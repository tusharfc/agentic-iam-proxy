# Security Policy

## Supported Versions
Currently, only the latest major release of Agentic IAM Proxy receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |

## Reporting a Vulnerability
Please do not report security vulnerabilities through public GitHub issues.
If you believe you have found a security vulnerability in Agentic IAM Proxy, please email **tshrkumar9@gmail.com**.

We take all security reports seriously and will acknowledge your email within 48 hours. We ask that you give us a reasonable timeframe to patch the vulnerability before disclosing it publicly.
